# Wanderlust

Wanderlust is a full-stack travel listing web application where users can explore travel destinations, create listings, and share reviews.

## Features

- User registration and login
- User authentication with Passport.js
- Create travel listings
- View travel listings
- Edit and delete listings
- Add reviews and ratings
- Flash messages for success and error notifications
- Session-based authentication
- Server-side validation
- Responsive frontend

## Tech Stack

- **Frontend:** HTML, CSS, EJS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **ODM:** Mongoose
- **Authentication:** Passport.js
- **Templating:** EJS and EJS-Mate
- **Validation:** Joi
